## 프로시저럴 생성 코드 실습 및 주요 파라미터 정리

- BSP 던전 생성 (bsp_dungeon.py)
  공간이 분할되는 과정, 방과 통로가 연결되는 과정, 중복 통로가 제거되는 과정 등을 직접 확인 
 
  TILE → 타일 한 칸의 크기를 설정하는 값
  COLS → 던전 맵의 가로 크기를 설정하는 값
  ROWS → 던전 맵의 세로 크기를 설정하는 값
  MIN_CELLS → 공간 분할 최소 크기를 설정하는 값
  HALL_WIDTH → 통로의 폭을 설정하는 값


- Cellular Automata 동굴 (cellular_cave.py)
  무작위로 생성된 지형이 반복 연산을 거치며 자연스러운 동굴 형태로 변화하는 과정을 시각적으로 확인

  TILE_SIZE → 타일 한 칸의 크기를 설정하는 값
  FILL_PROB → 초기 벽 생성 확률을 설정하는 값→ 동굴의 밀도에 영향을 줌
  ITERATIONS → 시뮬레이션 반복 횟수를 설정하는 값
  BIRTH_LIMIT → 주변 벽 개수에 따라 새로운 벽이 생성되는 기준값
  DEATH_LIMIT → 주변 벽 개수에 따라 벽이 사라지는 기준값

- Perlin Noise 지형 (perlin_terrain.py)
  노이즈 값을 이용해 산, 언덕, 물 지형 등을 자연스럽게 표현하며, 파라미터 값을 변경하여 지형의 높낮이나 굴곡 정도가 어떻게 달라지는지 확인

  SCROLL_SPEED → 지형이 이동하는 속도를 설정하는 값
  SCALE → 노이즈의 주파수를 설정하는 값
  OCTAVES → 노이즈 디테일 레이어 수를 설정하는 값
  AMPLITUDE  → 지형 높이의 진폭을 설정하는 값
  BASE_HEIGHT → 전체 지형의 기본 높이를 설정하는 값

## 파라미터 변경
- BSP 던전 생성 (bsp_dungeon.py)

  MIN_CELLS
  → 공간 분할 최소 크기를 결정하는 값
  → 값이 커질수록 큰 방 위주의 단순한 구조가 생성되고, 작아질수록 작은 방이 많아지며 복잡한 구조가 생성됨
  
  HALL_WIDTH
  → 통로의 폭을 결정하는 값
  → 값이 커질수록 넓고 개방적인 통로가 생성되며, 작아질수록 좁고 미로 같은 통로가 생성됨

- Cellular Automata 동굴 (cellular_cave.py)

  BIRTH_LIMIT
  → 값이 커질수록 새로운 벽 생성이 줄어들어 빈 공간이 많아지고, 작아질수록 벽이 쉽게 생성되어 동굴이 조밀해짐
  ITERATIONS
  → 값이 커질수록 지형이 더욱 자연스럽고 부드럽게 정리되며, 작아질수록 거칠고 불규칙한 형태가 유지됨

- Perlin Noise 지형 (perlin_terrain.py)

  SCALE
  → 값이 커질수록 지형 굴곡이 많고 복잡해지며, 작아질수록 완만하고 부드러운 지형이 생성됨
  AMPLITUDE
  → 값이 커질수록 산과 계곡의 높낮이 차이가 커지고, 작아질수록 평평한 지형이 생성됨
